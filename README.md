# YOLO11 Object Detection

This project performs real-time object detection using YOLO11 and OpenCV.

## Features

- Detects people
- Detects dogs
- Detects birds
- Object Tracking (IDs)

## Technologies

- Python
- OpenCV
- Ultralytics YOLO11
